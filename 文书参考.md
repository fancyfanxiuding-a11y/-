## Data source
All essays are manually copied from official university admission pages. Each entry keeps its original `source_url`.
Sources include JHU, Tufts, Emory admission official website.

## Dataset format
`data/essays.json`
- essay_id: unique id
- university: university name
- major: applicant major (undeclared if unknown)
- essay_type: common_app / supplemental_essay
- prompt: original essay prompt
- source_url: original web page
- source_type: where this essay is published
- copyright_note: usage warning
- content: full essay text
- admission_officer_comment: admission officer feedback
